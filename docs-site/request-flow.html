End-to-End Request Lifecycle

From client to database and back.

Step-by-Step

  1. Client crafts HTTP request with JSON body and optional JWT header.
  2. Express Router in src/routes matches path/verb and queues middleware + controller.
  3. Middleware (protect) verifies JWT, loads user, attaches req.user or returns 401.
  4. Controller validates input, guards ObjectId, orchestrates model calls, and builds response.
  5. Model (Mongoose) enforces schema, runs hooks (password hashing), executes queries.
  6. MongoDB persists/retrieves documents.
  7. Response returns structured JSON with success flag and data or error message.

Example: POST /api/services

  1. Client sends JSON body (title, description, price, category) and Authorization: Bearer <token>.
  2. Route router.post("/", protect, createService) matches.
  3. protect decodes JWT, fetches user, attaches req.user.
  4. createService validates required fields, constructs doc with createdBy, saves via Mongoose.
  5. Mongoose applies schema rules; MongoDB stores document.
  6. Controller returns 201 with { success: true, data: { service } }.

Example: GET /api/users/profile

  1. Client sends GET with Authorization header.
  2. Route uses protect then getProfile.
  3. Middleware verifies token, attaches user.
  4. Controller fetches user by req.user.id excluding password; 404 if missing.
  5. Returns 200 with data.user.
