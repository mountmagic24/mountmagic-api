Database & Schemas

MongoDB via Mongoose with schemas, fields, and relationships.

User

{ name: { type: String, required: true }, email: { type: String, required: true, unique: true }, password: { type: String, required: true }, role: { type: String, enum: ["admin","cd_manager","taxi_manager","content_manager","user"], default: "user" } } (timestamps)
  • Hashing: pre-save hook hashes passwords with bcrypt.
  • Uniqueness: email unique to prevent duplicates.
  • Roles: enum enables RBAC extension later.

Service

{ title: { type: String, required: true, trim: true }, description: { type: String, required: true, trim: true }, price: { type: Number, default: 0, min: 0 }, category: { type: String, trim: true }, createdBy: { type: ObjectId, ref: "User" } } (timestamps)
  • Required: title and description enforce meaningful entries.
  • Price: non-negative with default 0.
  • Relation: optional createdBy reference to User for ownership.

Blog

{ title: { type: String, required: true, trim: true }, content: { type: String, required: true, trim: true }, author: { type: ObjectId, ref: "User" } } (timestamps)
  • Required: title and content.
  • Relation: optional author reference to User.

Indexes & Validation

  • Email unique index on User (via unique: true).
  • Built-in validation: required fields, enum for role, min for price, trim for strings.
  • ObjectId validity checks happen in controllers before querying.
