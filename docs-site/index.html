Backend Overview

What this backend does, the problems it solves, and the technologies behind it.

Purpose

Mount Magic API is a production-style REST backend providing authentication, protected user profiles, service listings, blog content, and health checks. It demonstrates clean layering with Express, MongoDB, JWT auth, and comprehensive tests.

Problems solved
  • User onboarding and authentication (JWT)
  • Secure access to user profile data
  • CRUD for services (platform offerings)
  • CRUD for blogs (content publishing)
  • Liveness endpoints for monitoring
Key qualities
  • MVC-like structure with thin controllers
  • Protected routes via middleware
  • Schema-driven validation through Mongoose
  • End-to-end Jest + Supertest coverage
  • Env-driven config for prod/test separation

Tech Stack

Runtime Node.js (CommonJS)
Web Express 5
Database MongoDB + Mongoose
Auth JWT + bcrypt hashing
Config dotenv (.env, .env.test)
Testing Jest + Supertest (runInBand)

High-Level Design

Client
Express Route
Middleware (auth)
Controller
Mongoose Model
MongoDB
JSON Response

Routes stay declarative, middleware centralizes cross-cutting concerns, controllers coordinate validation and data access, and models enforce schema rules and hashing. Tests assert behavior at the HTTP boundary.
