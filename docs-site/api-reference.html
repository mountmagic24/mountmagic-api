API Reference

Endpoints, payloads, controllers, and example requests/responses.

Auth

MethodEndpointDescriptionController
POST/api/auth/registerRegister a userauthController.registerUser
POST/api/auth/loginLogin and receive JWTauthController.loginUser
POST /api/auth/register

Request JSON

{ "name": "Jane", "email": "jane@example.com", "password": "secret123" }

Response JSON

{ "success": true, "data": { "user": { "id": "64f...", "name": "Jane", "email": "jane@example.com", "role": "user" } } }

Errors: 400 missing fields; 409 duplicate email; 500 server error.

POST /api/auth/login

Request JSON

{ "email": "jane@example.com", "password": "secret123" }

Response JSON

{ "success": true, "data": { "token": "", "user": { "id": "64f...", "name": "Jane", "email": "jane@example.com", "role": "user" } } }

Errors: 400 missing fields; 401 invalid credentials; 404 user not found; 500 server error.

Users (protected)

MethodEndpointDescriptionController

GET /api/users/profile

Headers: Authorization: Bearer <token>

Response JSON

{ "success": true, "data": { "user": { "id": "64f...", "name": "User", "email": "user@test.com", "role": "user" } } }

Errors: 401 missing/invalid token; 404 user not found.

PUT /api/users/profile

Headers: Authorization: Bearer <token>

Request JSON

{ "name": "New Name", "email": "new@example.com", "password": "newpass" }

Response JSON

{ "success": true, "data": { "user": { "id": "64f...", "name": "New Name", "email": "new@example.com", "role": "user" } } }

Errors: 401 unauthorized; 404 user not found; 409 email in use.

Services

MethodEndpointDescriptionController
GET/api/servicesList servicesserviceController.getServices
GET/api/services/:idGet a serviceserviceController.getServiceById
POST/api/servicesCreate service (auth)serviceController.createService
PUT/api/services/:idUpdate service (auth)serviceController.updateService
DELETE/api/services/:idDelete service (auth)serviceController.deleteService
POST /api/services

Headers: Authorization: Bearer <token>

Request JSON

{ "title": "Climbing", "description": "Guided climbs", "price": 120, "category": "outdoors" }

Response JSON

{ "success": true, "data": { "service": { "_id": "64f...", "title": "Climbing", "description": "Guided climbs", "price": 120, "category": "outdoors", "createdBy": "64f..." } } }

Errors: 400 missing title/description; 401 unauthorized.

GET /api/services/:id

Returns 200 with service or 404 if missing/invalid id.

PUT /api/services/:id

Headers: Authorization: Bearer <token>

{ "description": "Updated desc" }

Errors: 401 unauthorized; 404 not found/invalid id.

DELETE /api/services/:id

Headers: Authorization: Bearer <token>

200 on delete; 401 unauthorized; 404 not found/invalid id.

POST /api/blogs

Headers: Authorization: Bearer <token>

Request JSON

{ "title": "Trip Report", "content": "Snowy and clear skies." }

Response JSON

{ "success": true, "data": { "blog": { "_id": "64f...", "title": "Trip Report", "content": "Snowy and clear skies.", "author": "64f..." } } }

Errors: 400 missing title/content; 401 unauthorized.

GET /api/blogs/:id

200 with blog; 404 invalid/missing id.

PUT /api/blogs/:id

Headers: Authorization: Bearer <token>

200 updated blog; 401 unauthorized; 404 not found/invalid id.

DELETE /api/blogs/:id

Headers: Authorization: Bearer <token>

200 on delete; 401 unauthorized; 404 not found/invalid id.
